# UNDERY — 개인 포트폴리오

참고 이미지의 아이보리 색감, 큰 타이포그래피, 캐릭터 레이어, 사진과 커뮤니티 구성을 HTML5 · CSS · JavaScript로 구현한 한 페이지입니다.

기본 디자인 기준은 **1920×1080**입니다. 데스크톱에서는 콘텐츠 폭을 1200px로 중앙 배치하고, 작은 화면에서는 가용 너비에 맞춰 줄어듭니다. 상단 UNDERY 제목은 실제 글자 폭과 끝부분 여백을 확보해 Y가 잘리지 않도록 구성했습니다.

## 실행

- **가장 간단한 방법:** `dist/index.html` 파일을 브라우저로 엽니다. 인터넷이나 설치 없이 작동합니다.
- **localhost:** `Start.cmd`를 더블 클릭합니다. `http://localhost:4173`에서 열립니다. 실행 창을 유지하고, 종료할 때 Ctrl+C를 누릅니다.
- **명령어:** 이 폴더에서 `npm start` 또는 `node server.mjs`를 실행합니다. 패키지를 설치할 필요는 없습니다.
- 다른 포트는 PowerShell에서 `./Start.ps1 -Port 4180 -OpenBrowser`로 실행할 수 있습니다.

## 사용

- 사진 클릭 → 크게 보기. 화면의 화살표 또는 키보드 ← / →로 이동합니다.
- 휴대폰에서는 사진을 좌우로 밀어 이동합니다.
- Esc, 닫기 버튼 또는 창 바깥 클릭으로 닫습니다.
- 프로필 보기, 사진 더 보기, 맨 위로 이동을 지원합니다.
- 데스크톱과 모바일 화면에 맞춰 배치가 바뀝니다.

## 수정

- `dist/index.html`: 소개 문구와 페이지 구조
- `dist/styles.css`: 색상, 글꼴, 여백과 반응형 디자인
- `dist/content.js`: 사진 제목, 친구 이름, SNS 주소
- `dist/app.js`: 갤러리와 모달 동작
- `dist/assets/photos/`: 공유 대화의 8K 보정본 6장과 그중 세로 원본에서 배경을 제거한 메인 이미지

실제 계정/초대 주소가 제공되지 않아 SNS 카드는 ‘연결 준비 중’ 안내를 표시합니다. `content.js`의 `socials`에 있는 `url`에 실제 주소를 입력하면 새 탭으로 연결됩니다. 친구 이름은 참고 이미지와 같은 예시이며, 게임 카드는 준비 중 상태입니다. 프로필 소개는 샘플 문구이므로 필요에 맞게 수정하세요.

사진과 배경은 사용자가 지정한 「사진 화질 개선」 공유 대화의 보정본 6장만 사용합니다. 갤러리 파일은 내려받은 8K PNG 그대로이며, 화면에서는 비율을 유지해 표시합니다. 사진 확대 창에서 전체 구도를 보고 「8K 원본 저장」으로 내려받을 수 있습니다. 메인 캐릭터만 세로 원본에서 배경 제거 편집을 했습니다. 출처와 처리 내역은 `IMAGE-SOURCES.md`, 편집 프롬프트는 `IMAGE-PROMPTS.md`에 기록합니다. 이전에 새로 생성한 이미지 3장은 배포 폴더에서 제외했습니다.

사용 폰트는 Anton, Cormorant Garamond, Pretendard입니다. 공식 배포 파일과 SIL OFL 라이선스를 함께 포함했으며, 확인한 출처는 `FONTS.md`에 있습니다. HTML에서 `fonts.css`를 불러와 실제 글꼴로 표시합니다.

브라우저에서 사진 확대 및 이전/다음 이동, 키보드 ←/→·Esc, 프로필 창, SNS 준비 중 안내를 확인했습니다. 320px·390px·768px·1280px 화면에서 가로 넘침을 점검했으며, 브라우저 오류 로그와 JavaScript/실행 스크립트 문법 검사도 통과했습니다.

별도 프레임워크, 빌드 과정, 외부 CDN이 필요하지 않습니다. `dist` 폴더 전체를 정적 웹 호스팅에 올려도 동작합니다.
